## 📌 Project Overview

The **Restaurant Data Cleaning Project** focuses on cleaning, preprocessing, and transforming raw restaurant datasets into structured and meaningful information.

The primary objective is to improve data quality by identifying missing values, handling duplicates, standardizing inconsistent data, correcting data types, and preparing the dataset for further analysis.

This project demonstrates practical data cleaning and preprocessing techniques using Python and its popular data science libraries.

## 🎯 Project Objectives

- Clean and preprocess raw restaurant datasets.
- Identify and handle missing values.
- Detect and manage duplicate records.
- Standardize inconsistent categorical values.
- Correct data types and formatting issues.
- Improve overall dataset quality.
- Prepare clean data for Exploratory Data Analysis (EDA).

## 🔍 Data Cleaning Operations

The project covers the following data preprocessing techniques:

1. **Data Inspection**
   - Understanding dataset structure.
   - Checking rows and columns.
   - Identifying data types.

2. **Missing Value Handling**
   - Identifying null values.
   - Analyzing missing data.
   - Handling missing values appropriately.

3. **Duplicate Detection**
   - Identifying duplicate records.
   - Checking data consistency.

4. **Data Standardization**
   - Cleaning inconsistent categorical values.
   - Standardizing text formats.
   - Removing unwanted spaces.

5. **Data Type Correction**
   - Converting columns into appropriate data types.
   - Handling numerical and categorical data.

6. **Data Validation**
   - Checking cleaned data.
   - Ensuring consistency and reliability.

## 📊 Dataset Description

The restaurant dataset contains information related to restaurant operations and customer preferences.

- Aggregate Rating
